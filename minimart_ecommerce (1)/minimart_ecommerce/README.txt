MiniMart E-commerce Website

Files:
- index.html: page structure
- style.css: website design and responsive layout
- script.js: product search, cart, quantities, and total calculations

How to run:
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open it in your browser.

Note: This is a front-end demo. Real payments and order placement are not connected.
